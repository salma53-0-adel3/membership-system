# Gym Membership Management System 🏋️‍♂️

A simple command-line application built in Python to manage gym memberships. This project is part of my coding journey to practice Object-Oriented Programming (OOP) and build interactive CLI applications.

## 🚀 Features
- **Add New Members:** Register members with their First Name, Last Name, ID, and Membership Status.
- **Display All Members:** View a list of all registered members and their details.
- **Search Functionality:** Search for members using:
  - Membership Status (Active/Inactive)
  - First Name
  - Membership ID
- **User-Friendly Interface:** Includes input validation and automatic screen clearing for a better user experience.

## 🛠️ Technologies Used
- **Python 3**
- Built-in modules: `os`, `time`

## 💻 How to Run
1. Make sure you have Python installed on your machine.
2. Clone this repository or download the `oop-gym-system.py` file.
3. Open your terminal/command prompt and navigate to the project folder.
